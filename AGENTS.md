Critical Next 16 changes that will break code if missed:
- **Async Request APIs**: `params`, `searchParams`, `cookies()`, `headers()` are now Promises. Must `await` them. Use `PageProps<'/route'>` and `LayoutProps<'/route'>` global type helpers (generated by `next dev` / `next typegen`).
- **Turbopack is default**: `turbopack` config moved from `experimental.turbopack` to top-level `turbopack` in `next.config.ts`.
- **`middleware` → `proxy`**: file and export renamed; runtime is `nodejs` (not edge).
- **`next lint` removed**: use `eslint` CLI directly (already wired in `package.json`).
- **`revalidateTag` requires 2 args**: second arg is a `cacheLife` profile string.
- **PPR**: `experimental.ppr` / `experimental_ppr` removed; use top-level `cacheComponents: true`.
- **Parallel routes**: every `@slot` now requires a `default.js` or build fails.
- **Images**: `images.domains` deprecated → use `remotePatterns`; `minimumCacheTTL` default changed to 4h; `qualities` default is `[75]` only.
- **Removed**: AMP support, `serverRuntimeConfig`/`publicRuntimeConfig`, `unstable_rootParams`, `experimental.dynamicIO`, `experimental.useCache`.

# Voltatrips Client

Headless Next.js front-end for the Voltatrips tourism/booking platform (WordPress + WPGraphQL + WooCommerce backend).
Dev server runs on **port 3001** (not 3000).

## Commands

| Script          | Description                                            |
| --------------- | ------------------------------------------------------ |
| `npm run dev`   | Starts `next dev -p 3001` (Turbopack by default).      |
| `npm run build` | `next build` (Turbopack).                              |
| `npm run lint`  | ESLint flat config — `next lint` was removed in v16.   |
| `npm run start` | `next start` — local production preview.               |

No tests / typecheck scripts are configured yet.

## Project layout

- `app/` — App Router entrypoint (`layout.tsx`, `page.tsx`, `globals.css`, `favicon.ico`).
- `public/` — static assets served at root.
- No `src/` directory; app code lives directly under `app/`.
- `@/*` path alias resolves to the **project root** (not `./src`).

## Stack

- **Framework**: Next.js 16.3.6 — App Router, React Server Components by default, Server Actions for mutations.
- **React**: 19.2.8 (App Router uses React Canary channel).
- **Styling**: Tailwind CSS v4 — configured via `@import "tailwindcss"` in `app/globals.css`; no `tailwind.config.*`. PostCSS plugin is `@tailwindcss/postcss`.
- **TypeScript**: strict mode, `moduleResolution: "bundler"`, `@/*` → root.
- **Package manager**: npm (`package-lock.json`).

## Data layer (GraphQL)

No Faust.js, no Apollo Client. Data is fetched with plain `fetch` to the WPGraphQL endpoint (`WORDPRESS_GRAPHQL_ENDPOINT` env). Mutations that mutate WordPress data go through **Server Actions**.

Key WP plugins (backend, not installed here — document for context):
- WPGraphQL + WooCommerce GraphQL + Rank Math GraphQL + `axepress/wp-graphql-headless-login`

## Authentication & session

No NextAuth. Lightweight session handling via Server Actions:
- Session payload (`authToken`, `refreshToken`, `userId`, `role`) is encrypted into an **httpOnly cookie** with `jose`.
- `getSession()` helper reads the cookie and performs **silent token refresh** in the background.
- **Route protection**: in Next.js 16 the `middleware.ts` convention is deprecated and renamed to **`proxy.ts`** (export `proxy` function). Its runtime is fixed to `nodejs`; the `edge` runtime is **not supported** in `proxy.ts`. If edge runtime is ever required, keep using `middleware.ts` explicitly.

## Deferred (not in current build)

These are explicitly out of scope for now and only noted to prevent accidental implementation:
- QR / voucher & ticket downloads in dashboard.
- Live draft preview (`draftMode()`) and the `/api/draft` route handler.
- Gutenberg block rendering via `html-react-parser` with `<Image/>` replacement.
